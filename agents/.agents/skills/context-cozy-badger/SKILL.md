# Cozy Badger context

## Purpose and audience

Cozy Badger develops open-source software that solves business problems for
small businesses and solopreneurs. Make tools simple enough for non-technical
customers to use without ongoing technical assistance.

- Small businesses include restaurants, workshops, and small shops.
- Solopreneurs include coaches, freelancers, and trainers across industries.
- Public projects include customer-facing software and supporting tools for
  development, operations, and managing Cozy Badger's own customer base.
- Not every tool targets end customers. Confirm the users of the current
  project before choosing workflows, terminology, or interface complexity.

## Apply the core values

- **Customer focus:** Start with the customer's problem and desired outcome.
  Prefer useful workflows over features added for technical novelty.
- **Social responsibility:** Work fairly and transparently. Respect users,
  contributors, and maintainers. Treat open source as a core commitment;
  preserve the project's license and attribution requirements.
- **Simplicity:** Minimize setup, steps, and unnecessary complexity. Use plain
  language, understandable defaults, and actionable error messages.
- **Reliability:** Favor stable, secure behavior. Protect customer data and
  preserve existing workflows. Make failures visible and recoverable.
- **Environmental awareness:** Avoid unnecessary computation, data transfer,
  storage, and infrastructure. Prefer resource-efficient solutions without
  compromising correctness, security, or usability.
